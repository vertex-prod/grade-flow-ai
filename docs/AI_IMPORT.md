# GradeFlow AI: AI import

1. **SF9** (`POST /api/import`): the server sends only the top ~15 rows and the list of target fields to the AI, which answers with a column mapping (JSON). **Code, not the model, copies every value** from the sheet. No grade is generated by AI; blank stays blank. If the AI is unavailable, the built-in template reader is used.
2. **SF10** (`POST /api/import-sf10`): an SF10 is a form, so the AI reads the whole sheet (one learner per sheet) and returns the record. Every grade it returns is checked against the sheet's own cells; a value that is not in the sheet is dropped.


## Class details accuracy

The AI also reads class details (school, adviser, principal, section, school year, grade level, track). These are checked by code in `src/server/import/details.ts`:

- Any value the AI returns that is **not written in the sheet** is dropped and reported in the warnings (same rule as grades).
- Labelled cells ("Adviser: MS. GALLO", "School Year:" next to "2024-2025") are read by code and win over the AI when they disagree.
- School year is stored as `2024-2025`, grade level as `11`/`12`, semester as `1`/`2`.
- In SF10, each semester block's school, track, section, adviser and principal must appear in the sheet; the learner name is checked and a warning is shown if it is spelled differently.
